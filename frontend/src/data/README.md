# Agriculture map boundary data

The bundled state and district GeoJSON files contain boundaries derived from
OpenStreetMap data. The database is available under the
[Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).

Credit map data as **© OpenStreetMap contributors** and link to
<https://www.openstreetmap.org/copyright>. If distributing an adapted version
of the boundary database, follow the ODbL share-alike terms.

These boundaries are for general visualisation only. They are not official
Government of India boundaries or survey-grade data. The files include state
and district boundaries only; they do not contain village boundaries or
agricultural statistics.
